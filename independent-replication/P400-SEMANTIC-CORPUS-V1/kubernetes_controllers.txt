Controllers

In robotics and automation, a control loop is a non-terminating loop that regulates the state of a system.

In Kubernetes, controllers are control loops that watch the state of your cluster, then make or request changes where needed. Each controller tries to move the current cluster state closer to the desired state.

A controller tracks at least one Kubernetes resource type. These objects have a spec field that represents the desired state. The controller(s) for that resource are responsible for making the current state come closer to the desired state.

The controller might carry the action out itself; more commonly, a controller will send messages to the API server that have useful side effects. The Job controller is an example of a built-in controller. Built-in controllers manage state by interacting with the cluster API server.
